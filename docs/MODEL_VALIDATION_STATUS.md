## 二、状态定义与准入原则

### 1. 四项独立验证维度
- **`is_algorithm_fitted` (算法拟合)**：
  表示模型优化算法（如梯度提升树、Nelder-Mead、Newton-Raphson）在输入样本上已成功达到收敛条件，损失函数已稳定。
- **`is_data_verified` (数据核验)**：
  表示用于训练的所有样本记录具备不可篡改的数据来源、首次公开时间戳 (`published_at`)、无未来信息倒挂，且数据质量经审计认证为 `DataQualityStatus.VERIFIED`。
- **`is_out_of_sample_validated` (样本外验证)**：
  表示模型在未见过的后续时序窗口（Walk-Forward 截面）上验证通过，不存在过拟合与数据泄漏。
- **`is_calibrated` (概率校准)**：
  表示模型输出的概率分布经过独立测试集上的 Brier Score、Platt 缩放或保序回归校准，使其统计概率与实际发生频率一致。

### 2. 双轨排序治理机制
- **研究关注度排序 (Research Ranking)**：
  基于宏观环境、技术加速度、产业链壁垒与扩散阶段等**客观非概率指标**综合赋分 (0~100)，供量化研究员进行候选跟踪，不作投资保本收益承诺。
- **正式预测排名 (Verified Forecast Ranking)**：
  仅接受同时满足 `is_data_verified=True`、`is_out_of_sample_validated=True` 与 `is_calibrated=True` 的生产级模型 (`VERIFIED_PRODUCTION`) 输出。
  **在当前阶段，全系统正式预测排名严格返回空 (`NO_VERIFIED_FORECASTS`)，真实反映系统能力边界。**
