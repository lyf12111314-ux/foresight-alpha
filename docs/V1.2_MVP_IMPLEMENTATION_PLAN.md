## 一、明确范围与非目标 (Scope & Non-Goals)

### 本轮最小实现范围（仅围绕 Task A 试点闭环）
1. **修复 `OpenAlexCollector` 前视泄露**：剥离当前累计 `cited_by_count` 与 `*12` / `*0.15` 机构估算，改为基于 `counts_by_year` 按 `year <= T_0` 严格截断引用，并支持将原始 HTTP 响应落盘至本地规范化快照文件与 SHA-256 存证。
2. **隔离历史 `GitHub` 特征**：在历史回测与 `tech_training_samples` 历史构造中，禁止填入当下 `stargazers_count`，对无法证明历史可获得性的字段显式置 `None`。
3. **构建多赛道 Task A 真实面板（扩展自固态电池试点）**：将固态电池试点扩展至 10–15 个覆盖成长期与放缓/退潮期的技术主题（2013–2025 年），形成首个可进入 `TrustedValidationRegistry` 真实检验的 Task A 跨周期样本集。
4. **独立样本外评估与 Walk-Forward 验证**：使用早期真实样本拟合、独立后期已成熟真实样本评估（$\text{MAE}$ 与基准对比），达标才晋升，不达标则如实保留 `BENCHMARK` / `EXPERIMENTAL` 状态。

### 明确非目标 (Non-Goals)
- 不虚构 Task B（产业商业化）或 Task C（投资收益）的历史标签；
- 不调整 `MAE <= 2.0`、`C-index >= 0.60` 等生产准入门槛；
- 不在未完成真实样本核验前启动 V2.0 新模型架构开发。

## 三、后续独立数据建设任务清单（解决当前“不可验证”部分）

针对本轮明确回答不了的 **Task B（商业化）** 与 **Task C（投资收益）**，列为 V1.2 阶段 2/3 专项数据任务：

1. **Task B 数据建设（企业财报与违约队列）**：
   - 接入公开无密钥财经接口（如 AKShare / 巨潮公告或 SEC EDGAR）拉取固态电池产业链及对照行业历史财报与 ST/退市公告；
   - 必须保留公告首次发布日 `published_at`（严格区分会计期末与实际年报披露日）及原始响应 SHA-256，替换 `src/ingestion/enterprise.py` 中的 `MANUAL_REFERENCE` 硬编码元组。
2. **Task C 数据建设（可交易资产全收益标签）**：
   - 对接交易所复权日线行情与分红除权记录（含已退市标的，避免幸存者偏差）；
   - 按明确证券代码计算持有期全收益倍数 $P_{\text{adj}}(T_0 + H) / P_{\text{adj}}(T_0)$，使“投资收益预测”拥有独立可核验的真实标签。
3. **Macro 初值（Vintage）核验**：
   - 为 `src/ingestion/macro.py` 补充发布日历与初值快照留存机制，消除 GDP/工业利润事后年度修订带来的轻微回测偏差。
