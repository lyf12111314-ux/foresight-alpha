# Foresight Alpha V1.2 — 预测对象与真实标签规范 (`V1.2_TARGET_DEFINITION.md`)

> **试点主题**：固态电池（Solid-State Battery）  
> **核心纪律**：严禁将“学术论文增速”“产业营收扩张”与“二级市场股票收益”混用同一个增长倍数标签。三类预测任务必须拥有各自独立的预测对象、计量单位、真实计算公式、观察期终点与首次可获取时间。若缺乏可靠外部真实数据，直接判定为**不可验证（`UNVERIFIABLE`）**，绝不编造历史结果。

---

## 一、三类预测任务严格隔离总览

| 任务编号 | 任务名称 | 预测对象 | 能否由 OpenAlex 单独验证 | 当前试点数据可用性 |
| :--- | :--- | :--- | :--- | :--- |
| **Task A** | 技术成长预测 | 固态电池公开科研产出规模（年度论文数） | **是**（存在索引补录误差，需注明） | **已有真实证据支持（试点可验证）** |
| **Task B** | 产业商业化预测 | 产业/代表企业固态电池相关真实营业收入、出货量或毛利率 | **否**（论文不能代表商业化） | **尚待核验（需阶段 2 接入年报/官方产能统计）** |
| **Task C** | 投资收益预测 | 明确可交易权益资产（含代码、复权收盘价与分红）区间总回报率 | **否**（技术/商业化不等于股价收益） | **尚待核验（需接入交易所复权行情数据）** |

---

## 二、Task A：技术成长（Technical Diffusion & Research Growth）

- **预测对象与计量单位**：固态电池领域年度公开发表学术文献数量倍数（`paper_growth_multiple`，无量纲倍数，基准单位：篇/年）。
- **预测起点 ($T_0$)**：截面年年末（示例：`2020-12-31`），仅允许使用发表年份 $\le T_0$ 的文献特征。
- **预测期限 ($H$)**：独立分期限评估：$H \in \{1\text{ 年}, 3\text{ 年}, 5\text{ 年}\}$。
- **真实结果计算公式**：
  $$y_{A}(T_0, H) = \frac{N_{\text{papers}}(T_0 + H)}{N_{\text{papers}}(T_0)}$$
  其中 $N_{\text{papers}}(Y)$ 为 OpenAlex 查询 `search="solid-state battery"&filter=publication_year:{Y}` 返回的年度文献总数（基期分母要求 $N_{\text{papers}}(T_0) > 0$，否则该样本标签置 `None`）。
- **标签观察期终点**：$T_{\text{end}} = \text{date}(Y_0 + H, 12, 31)$（如 $T_0 = \text{2020-12-31}$ 时，3 年期终点为 `2023-12-31`，5 年期终点为 `2025-12-31`）。
- **标签首次可获取时间**：次年 Q1 索引基本稳定后（保守设定为 $T_{\text{avail}} = \text{date}(Y_0 + H + 1, 3, 31)$，并须 $\le$ 当前物理日期）。
- **数据来源**：OpenAlex Works API (`https://api.openalex.org/works`)，需留存原始 JSON 响应及 SHA-256 哈希。
- **缺失与未成熟处理方式**：
  - 若 $T_{\text{avail}} > T_{\text{now}}$ 或 $T_{\text{end}} > T_{\text{now}}$：标签状态严格设为 `NOT_MATURED`，`target = None`，绝不计入回测成败分母；
  - 若分母 $N_{\text{papers}}(T_0) \le 0$ 或接口请求失败：`target = None`，记录为 `MISSING_OBSERVATION`；
  - **已知局限声明**：OpenAlex 存在跨年回溯索引补录，因此当前查询到的 2023/2025 年文献数与当年年底实时索引数可能存在小幅差异，应在报告中披露为**近似静态复现（需长期固化快照消除补录偏差）**。

## 三、Task B：产业商业化（Industrial Commercialization）

- **预测对象与计量单位**：
  1. 代表企业核心业务营业收入增速倍数（单位：亿元人民币或百万美元，同比/跨期倍数）；
  2. 产业真实装机量/出货量（单位：GWh/年）与经营毛利率（单位：%）。
- **预测起点 ($T_0$)**：仅限基于截至 $T_0$ 已公开披露的最新年报/季报截断（例如 `2020-12-31` 截面只能使用 `2020-10-31` 前已发布的三季报或 `2019` 年报，**严禁在 2020-12-31 使用 2021 年 4 月才公告的 2020 年年报**）。
- **预测期限 ($H$)**：$H \in \{1\text{ 年}, 3\text{ 年}, 5\text{ 年}\}$。
- **真实结果计算公式**：
  $$y_{B,\text{rev}}(T_0, H) = \frac{\text{Revenue}(Y_0 + H)}{\text{Revenue}(Y_0)}, \quad \Delta \text{GM} = \text{GM}(Y_0 + H) - \text{GM}(Y_0)$$
  要求基期 $\text{Revenue}(Y_0) > 0$，且需基于**首次公告财报数据**（或显式标注经后续会计调整的数据）。
- **标签观察期终点**：对应会计年度结束日 `date(Y_0 + H, 12, 31)`。
- **标签首次可获取时间**：目标年度年报实际公告日 `published_at`（A 股通常为次年 `4月30日` 前，美股 10-K 通常为次年 `3月底` 前）。
- **数据来源**：交易所官方披露（巨潮资讯 CNINFO / 上交所 / 深交所 / SEC EDGAR / 经核验财经接口如 AKShare），**不接受未经原始公告编号核验的手工录入数字**。
- **缺失与未成熟处理方式**：
  - 当前阶段尚无逐笔审计的固态电池代表企业官方财报接口快照：**Task B 当前判定为“尚待核验 / 暂不可验证（`UNVERIFIABLE`）”**，在阶段 2 接入真实财报快照前，严禁使用 `enterprise.py` 中的 `MANUAL_REFERENCE` 数据作为真实标签。

## 四、Task C：投资收益（Investable Asset Total Return）

- **预测对象与计量单位**：明确可交易权益资产（例如指定 A 股/美股固态电池产业链标的或行业 ETF，须绑定具体证券代码、交易所与币种）在持有期内的**含分红全收益倍数**（`total_return_multiple`，无量纲倍数，或百分比收益率）。
- **预测起点 ($T_0$)**：建仓交易日收盘后（例如 `2020-12-31` 最后一个交易日收盘价，且仅能使用该日收盘前已公开的信号）。
- **预测期限 ($H$)**：$H \in \{1\text{ 年}, 3\text{ 年}, 5\text{ 年}\}$ 对应交易日。
- **真实结果计算公式**：
  $$y_{C}(T_0, H) = \frac{P_{\text{adj}}(T_0 + H)}{P_{\text{adj}}(T_0)}$$
  其中 $P_{\text{adj}}$ 为包含现金分红再投资、送转股与拆股调整的**后复权（或前复权基准一致）收盘价**；若标的中途退市，按退市最后交易日清算残值计价（严禁剔除退市股造成幸存者偏差）。
- **标签观察期终点**：$T_0 + H$ 对应的实际交易日（若非交易日，顺延至最近有效交易日）。
- **标签首次可获取时间**：$T_{\text{end}}$ 当日收盘行情发布时（即当日即可获得，无财报滞后）。
- **数据来源**：交易所官方日线行情与分红除权记录（需独立对接行情接口并留存快照哈希）。
- **缺失与未成熟处理方式**：
  - 当前代码库尚未接入任何真实复权日线行情与分红数据集，且 `asset_mapping.py` 仅提供赛道-标的映射关系、不含历史价格序列；
  - **Task C 当前判定为“无法获得历史证据（待接入行情接口）/ 暂不可验证（`UNVERIFIABLE`）”**，严禁将学术论文增长倍数或蒙特卡洛模拟 `10x` 概率等同于真实投资收益。
