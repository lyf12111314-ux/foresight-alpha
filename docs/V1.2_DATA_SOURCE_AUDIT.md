## 二、审计结论汇总

| 模块 | 真实证据状态 | 核心阻断缺陷 | V1.2 处置原则 |
| :--- | :--- | :--- | :--- |
| `openalex.py` | **部分真实 / 尚待核验** | `cited_by_count` 泄露未来引用；机构数为经验估算；缺快照落盘 | **优先改造试点**：改用 `publication_year` 文献量 + `counts_by_year` 按年截断引用，并落盘原始响应 |
| `github.py` | **无法获得历史证据** | Search API 仅返回当下实时 Star，2020 年历史仓库大量不存在 | **禁止用于历史回测特征**，仅保留前瞻实时监控 |
| `macro.py` | **尚待核验** | 缺初值（Vintage）快照，存在宏观数据事后修订偏差 | 后续需补充发布日历与初值快照校验 |
| `enterprise.py` | **不适合进入正式模型** | 全量为手写 `MANUAL_REFERENCE`，缺原始财报与公告接口 | V1.2 阶段 2 用公开财报/公告接口替换 |
| `tech_dataset.py` | **不适合进入正式模型** | 全量为手写 `MANUAL_REFERENCE`，特征与标签定义混杂 | V1.2 阶段 1 用本轮严格定义的真实样本重建 |
